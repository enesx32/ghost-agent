# Contributing to GhostAI

Thanks for considering contributing to GhostAI!

GhostAI is an open-source project, and contributions of all sizes are welcome. Whether you're fixing a bug, improving existing functionality or adding something new, your help is appreciated.

## Guidelines

We don't have a complicated contribution process. Just follow a few basic principles:

### 1. Keep It Simple

- Write clean, readable and maintainable code.
- Avoid unnecessary complexity.
- Follow the existing project structure and coding style.

### 2. Limited LLM Use

AI tools can be useful, but contributions should reflect your own understanding and work.

- Use of LLMs should be limited.
- Do not submit entirely AI-generated implementations without reviewing and understanding them.
- Contributors are responsible for the correctness and quality of their submissions.

### 3. Dependencies

GhostAI aims to use Python's standard library exclusively.

Avoid introducing third-party dependencies unless absolutely necessary.

Maintain compatibility with Python 3.8 and newer.

### 4. Testing

**All existing tests must pass before a pull request is submitted.**

- Add tests for new functionality where appropriate.
- Do not knowingly introduce regressions.
- Make sure your changes work on supported platforms.

### 5. Pull Requests

When submitting a pull request:

- Give it a clear title.
- Briefly explain what you changed.
- Keep changes relevant to the purpose of the pull request.
- Make sure all tests pass.

That's it. No unnecessary paperwork.

## Bug Reports

Found a bug? Open an issue and include:

- What happened.
- How to reproduce it.
- What you expected to happen.
- Any relevant error messages.

Never include API keys or private credentials.

## Feature Requests

Have an idea? Open an issue describing what you'd like to see and why it would be useful.

Suggestions are always welcome.
